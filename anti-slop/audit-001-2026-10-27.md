# Markdown speaker notes: post-implementation review

Mode: after implementation, selected for this session.

Scope: the PDF notes picker, Markdown preview, phone notes, and their surrounding presentation controls. Existing visual direction is the corporate theme and current presenter workspace. ENERGY 1 / RHYTHM 1 / MOTION 1 for the notes feature.

## Findings awaiting approval

1. **HIGH, R-25: inherited notes-label contrast is below AA.** `src/App.css:40-46` sets `.eyebrow` to 55% of the body text color. The 11px “Speaker notes preview” label measures **3.87:1** against its white panel in Chromium, below the required 4.5:1 for normal text. The Markdown body measures **17.21:1**. Suggested fix: increase label contrast, checking other uses of `.eyebrow` before changing the shared rule.

2. **HIGH, R-03: inherited host navigation overflows at 196px viewport width.** `src/features/host/HostPage.tsx:372-398` keeps the previous button, minimum-width slide counter, and next button in one unwrapped row. Browser geometry identifies that row and its next button as the overflowing elements. The Markdown preview itself fits at 196px, including long code and unbroken text; the complete page fits at 393px and 1280px. Suggested fix: let the control row wrap or reduce the counter's minimum width at very narrow sizes.

These findings were recorded without changing the existing shared labels or slide-control layout. Select finding numbers before applying follow-up UI fixes.
